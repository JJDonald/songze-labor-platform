# 劳动课程平台

这是项目主应用目录。完整说明请查看仓库根目录的 [README.md](../README.md)。

## 常用命令

```bash
# 前端开发
npm install
npm run dev

# 前端检查/构建
npm run lint
npm run build

# 后端初始化与开发
cd server
cp .env.example .env
npm install
npm run db:generate
npm run db:push
npm run db:seed
npm run dev
```
